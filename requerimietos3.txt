Fórmulas Matemáticas y Lógica de Escenarios ExtremosEl motor se basa en la Diferencia de Suma ($\Delta$) entre el equipo ganador y el perdedor, agregando las bonificaciones y penalizaciones individuales según el rango del jugador dentro de la sala.$$\Delta = \text{Suma Equipo Ganador} - \text{Suma Equipo Perdedor}$$Lógica General de CálculoCálculo de PR Base por Victoria:$$\text{PR\_Victoria\_Calc} = \text{win\_base\_pr} - (\Delta \times \text{sum\_gap\_multiplier})$$$$\text{PR\_Victoria} = \text{Clamp}(\text{PR\_Victoria\_Calc}, \text{min\_pr\_win}, \text{max\_pr\_win})$$Cálculo de PR Base por Derrota:$$\text{PR\_Derrota\_Calc} = \text{loss\_base\_pr} + (\Delta \times \text{sum\_gap\_multiplier})$$$$\text{PR\_Derrota} = -\text{Clamp}(\text{PR\_Derrota\_Calc}, \text{min\_pr\_loss}, \text{max\_pr\_loss})$$Ajuste Individual por Rango (Se suma al resultado anterior):Si $\text{MMR\_Jugador} \le \text{low\_rank\_threshold}$ (ej. Jugador Rango D o C en sala alta) y gana:$$\text{PR\_Final} = \text{PR\_Victoria} + \text{low\_rank\_bonus}$$Si $\text{MMR\_Jugador} \ge \text{high\_rank\_threshold}$ (ej. Jugador Rango S) y gana:$$\text{PR\_Final} = \text{PR\_Victoria} - \text{high\_rank\_penalty}$$Explicación Metodológica de los Casos EspecialesEscenario A: Un equipo fuerte (S) le gana a un equipo débil (D) (Victoria Esperada)Comportamiento: La diferencia de suma $\Delta$ es muy alta y positiva.Resultado: La fórmula reduce los puntos ganados al mínimo configurado ($\text{min\_pr\_win} = +15\text{ PR}$).Perdedor (Equipo D): Pierde la cantidad mínima de puntos ($\text{min\_pr\_loss} = -10\text{ PR}$), evitando castigar a un equipo inferior por perder una partida desbalanceada.Escenario B: Un equipo débil (D) le gana a un equipo fuerte (S) (Hazaña / Upsell)Comportamiento: La diferencia de suma $\Delta$ es negativa (el ganador tenía menor suma total).Resultado: La resta $- (\Delta \times K)$ se convierte en suma, elevando la recompensa al tope máximo ($\text{max\_pr\_win} = +100\text{ PR}$).Perdedor (Equipo S): Es castigado con la pérdida máxima posible ($\text{max\_pr\_loss} = -50\text{ PR}$) por caer ante un equipo inferior.Escenario C: Un jugador Rango D está en un equipo Rango S y gananComportamiento: El equipo gana los PR correspondientes por el balance general de las sumas.Resultado para el Rango D: Al cumplir $\text{MMR} \le \text{low\_rank\_threshold}$, el sistema le otorga el Bono de Rango Bajo ($\text{low\_rank\_bonus} = +10\text{ PR}$). Si el equipo ganó $+50\text{ PR}$, el jugador D recibe $+60\text{ PR}$, ayudándolo a subir más rápido hacia el nivel de la sala.Escenario D: Un jugador Rango S está en un equipo Rango D y pierdenComportamiento: Si el equipo pierde por contar con menor suma total, la pérdida de PR se mitiga gracias a la brecha.Resultado para el Rango S: Al ganar se le aplica un ajuste ($\text{high\_rank\_penalty} = -10\text{ PR}$) para no inflar artificialmente el tope alto, pero si pierde en un equipo débil, la pérdida se mantiene baja para no castigarlo injustamente por el rendimiento global del equipo.4. Código Completo del Backend (TypeScript)TypeScriptinterface ModalityRankConfig {
  modality: string;
  pr_per_mmr_step: number;
  win_base_pr: number;
  loss_base_pr: number;
  sum_gap_multiplier: number;
  max_pr_win: number;
  min_pr_win: number;
  max_pr_loss: number;
  min_pr_loss: number;
  low_rank_threshold: number;
  low_rank_bonus: number;
  high_rank_threshold: number;
  high_rank_penalty: number;
}

interface Player {
  id: string;
  mmr: number;
  pr: number;
  rank: string;
}

interface MatchResultOutput {
  newPR: number;
  newMMR: number;
  newRank: string;
  prDelta: number;
}

function processMatchResult(
  player: Player,
  playerTeamSum: number,
  enemyTeamSum: number,
  isWinner: boolean,
  config: ModalityRankConfig
): MatchResultOutput {

  // 1. Calcular brecha de suma
  const gap = isWinner 
    ? (playerTeamSum - enemyTeamSum) 
    : (enemyTeamSum - playerTeamSum);

  let prChange = 0;

  if (isWinner) {
    // 2. Calculo base por victoria (A menor suma del ganador frente al perdedor, mayor es el premio)
    const calculatedWin = config.win_base_pr - (gap * config.sum_gap_multiplier);
    
    // Aplicar límites Min/Max
    prChange = Math.max(config.min_pr_win, Math.min(config.max_pr_win, calculatedWin));

    // 3. Ajustes individuales por rango del jugador
    if (player.mmr <= config.low_rank_threshold) {
      prChange += config.low_rank_bonus; // Caso C: Jugador D suma bono por ganar en sala alta
    } else if (player.mmr >= config.high_rank_threshold) {
      prChange -= config.high_rank_penalty; // Caso D: Control de inflación para rangos S
    }
  } else {
    // 4. Calculo base por derrota
    const calculatedLoss = config.loss_base_pr + (gap * config.sum_gap_multiplier);
    
    // Aplicar límites Min/Max y convertir a negativo
    prChange = -Math.max(config.min_pr_loss, Math.min(config.max_pr_loss, calculatedLoss));
  }

  // 5. Actualizar Puntos Acumulados
  const roundedDelta = Math.round(prChange);
  const newPR = Math.max(0, player.pr + roundedDelta);

  // 6. Recalcular MMR y Rango dinámicamente
  const newMMR = Math.floor(newPR / config.pr_per_mmr_step) * 0.5;
  const newRank = getRankNameFromMMR(newMMR);

  return {
    newPR,
    newMMR,
    newRank,
    prDelta: roundedDelta
  };
}

function getRankNameFromMMR(mmr: number): string {
  if (mmr <= 1.0) return "D";
  if (mmr === 1.5) return "D+";
  if (mmr === 2.0) return "C";
  if (mmr === 2.5) return "C+";
  if (mmr === 3.0) return "B";
  if (mmr === 3.5) return "B+";
  if (mmr === 4.0) return "A";
  if (mmr === 4.5) return "A+";
  if (mmr === 5.0) return "S";
  if (mmr === 5.5) return "S+";
  if (mmr === 6.0) return "S++";
  return "S+++";
}
